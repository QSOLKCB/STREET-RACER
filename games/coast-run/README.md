# COAST RUN — Sunset Checkpoints

An original, OutRun-inspired scenic highway mode using the shared racing modules. Reach the end of a 5.2 km road before the timer expires; each of three intermediate checkpoints adds 20 seconds. Coastal scenery is drawn procedurally. This is a playable game, not a placeholder.

Launch [index.html](index.html) from the built site or an HTTP server at the repository root.
