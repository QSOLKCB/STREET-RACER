# STREET RACER — existing garage game

The original STREET RACER remains at the **repository root** for URL, PWA, save-game and browser-test compatibility. Its source lives in `js/`, `style.css`, and `index.html`. This is a deliberate legacy package boundary, not an empty placeholder: it is playable at the existing GitHub Pages URL. Future migration into this directory requires a separately reviewed compatibility and offline-cache plan.

See [the racing hub](../../arcade-hub.html).
