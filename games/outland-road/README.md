# OUTLAND ROAD — Road Wars

An original road-combat arcade mode inspired by the feel of Outlander-era driving games. It has a two-lap wasteland route, seven hostile drivers, collision damage, limited ammunition, aim-by-lane firing, takedowns and ammunition regeneration. Uses no copyrighted game assets. This is a playable game, not a placeholder.

Launch [index.html](index.html) from the built site or an HTTP server at the repository root.

## RACING-002 combat polish

Rivals block the driver's lane within range, with bounded deterministic Q16.16 motion. Improved nitro momentum and swept longitudinal contact detection add arcade driving depth while preserving ammunition and takedown rules.
